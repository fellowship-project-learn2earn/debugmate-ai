# ImportError / ModuleNotFoundError
tags: importerror, modulenotfounderror, no module named

ModuleNotFoundError means Python can't find a package that's being imported -- usually because it isn't installed in the current environment, or there's a typo in the import statement, or the wrong virtual environment/interpreter is active. Fix by confirming the package name spelling, running pip install <package>, and checking which Python environment is actually running the code.
