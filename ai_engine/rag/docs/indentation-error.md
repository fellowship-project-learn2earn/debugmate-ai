# IndentationError
tags: indentationerror, unexpected indent, expected an indented block

IndentationError means Python's block structure doesn't add up -- mixing tabs and spaces, a missing indent after a colon (if/for/def/etc.), or an extra indent that doesn't match any block. Fix by using a consistent indent style (4 spaces is the Python convention) throughout the file, and checking that every line after a colon is indented one level deeper.
